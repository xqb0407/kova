# 移动端通用设计 Token 基线

## 间距阶梯（Spacing）

`4 / 8 / 12 / 16 / 24 / 32 / 48`（= space-1…space-7）。规则：
- 组件内部紧凑对 4-8；相关元素间 12-16；区块之间 ≥ 24；页面分节 32-48。
- **视觉亲疏 = 数值大小**：一组元素内部间距必须小于组与组的间距。
- 页边距左右一致（常用 16），滚动内容与页边同宽。

## 字号阶梯（size/line-height 成对取值）

```
28 / 36   页面大标题
22 / 28   区块标题
17 / 24   正文大号、列表主文字
15 / 22   正文
13 / 18   辅助说明、副标题
11 / 14   标签、图片角标
```
- 行高 ≈ 字号 × 1.4-1.5（大字比例收紧、小字放松）；段间距 = 1 个 space-2。
- 字重只用 3 档：400 正文 / 500-600 标题与强调 / 700 极少数主数字。层级差异优先"字号+颜色"，字重其次。

## 触控与热区

- 最小热区 **44×44**（保守 48×48）；图标视觉 20-28，热区外扩补足。
- 相邻可点元素间隔 ≥ 8；主操作放拇指可达的屏幕下半区。

## 圆角与描边

- 阶梯：4（标签）/ 8（输入、小按钮）/ 12（卡片、按钮）/ 16（大容器、弹层）/ 999（胶囊、头像）。
- 嵌套圆角：内层 = 外层 − 内边距（外 16 内衬 12 → 内圆角 4-8），避免"同心不圆"。
- 描边 1（发丝线 0.5 平台可用）、强调 1.5-2；同稿只用一档。

## 颜色与对比

- 结构：`bg / surface / surface-2`（抬升一层加深一档）+ `primary`（含 on-primary）+ 文字四级（主 87%、次 55-60%、占位 38%、禁用 38% 或 26%）+ `danger / success / warning` 语义四色。
- 对比度：正文文字 ≥ **4.5:1**，≥24px 大字 ≥ 3:1；图标/描边等 UI 部件 ≥ 3:1；主按钮文字与底色必须过 4.5:1。
- 彩色面积比 ≤ 90/7/3（中性底/辅助色/强调色）；一个界面只允许一个"最响"的强调色。

## 深浅主题映射

同名 token 双值，反转时遵守：
- 深色不是反色：底用近黑深灰（#101014 / #1C1C1E 类），**避免纯黑大面积**；文字用近白（87% 白）。
- 抬升逻辑：深色模式里"越高越亮"（surface、surface-2、surface-3 逐级 +6% 白）。
- 强调色降饱和提明度（浅 #007AFF → 深 #0A84FF 类），保证深色底对比。
- 阴影在深色里几乎无效：改用亮度差 + 1dp 描边分层。

## 组件状态矩阵（每个可交互组件都要画到）

| 状态 | 视觉处理 |
|---|---|
| default | 基线样式 |
| pressed | 叠加黑/白 10-12%（或整体降亮度一档），可加内缩 |
| disabled | 前景 → 文字级 38%、底色 → 中性 12%，去掉阴影 |
| focused | 1.5-2 强调色描边 + 外光环（2px @18% 透明） |
| error | danger 描边/文字 + 12-13px 错误说明行 |
| loading | 骨架/.spinner；禁止空白屏 |

## 阴影配方（elevation 三档够用）

```
S1  0 1 2  0 rgba(0,0,0,.06), 0 1 8 0 rgba(0,0,0,.04)   # 卡片
S2  0 4 12 0 rgba(0,0,0,.10), 0 2 4 0 rgba(0,0,0,.06)    # 浮层、下拉
S3  0 12 32 0 rgba(0,0,0,.18), 0 4 8 0 rgba(0,0,0,.10)   # 模态、弹层
```
同一层级的元素用同一档；阴影只表达"悬浮于内容之上"，不用于装饰。

## 画板与内容纪律

- 基线画板 375 或 390 宽 × 812/844 高；状态栏（时间 9:41）+ 底部手势条画进 frame 内。
- 一屏一画板；交互流按 左→右 排画板并命名（默认/填充/空/错误/加载/弹层展开）。
- 真实内容：真实文案、真实头像/图、带小数的金额与不整的日期；占位块灰度不超过两级。

# 远程访问指南

网页端是桌面助手的**远程入口**：所有 AI 处理、会话存储、文件操作都发生在你自己的桌面客户端里（pi-agent sidecar），网页通过 WebSocket 连接桌面端执行。**网页界面由应用自身提供**——开启远程访问后，桌面端会在同一端口同时提供网页（HTTP）与对话通道（WebSocket），无需另外部署任何网页。

## 工作原理

```
浏览器 ──http──▶ 桌面端网关（默认 0.0.0.0:8787）─┬─ 静态网页（打包时嵌进可执行文件，开发态读 out/）
        ──ws /ws──▶                            └─ WS 对话通道 ──▶ pi-agent sidecar
```

1. 桌面端：设置 → 远程访问 → 开启网关。
2. 手机/其他设备：**扫描设置页二维码**或访问显示的地址（如 `http://192.168.1.5:8787`），网页直接打开，配对码已自动填入；也可手动输入 6 位配对码。
3. 配对成功换取长效 token，之后即可使用（会话列表/历史/聊天/中断与桌面端一致）。
4. 桌面端与网页端可同时在线，共享同一份本地会话。

## 首次配对

- 配对码仅用于换取 token，输错 5 次该连接即被锁定，可随时在桌面端"换一个"。
- token 保存在浏览器 localStorage（键 `pi.remote`），之后连接不再需要配对码。
- 清除方法：网页端断线条的"重新配对"，或手动清除 localStorage。
- 二维码内容优先级：配置了"网页端地址"则扫码打开该地址；否则直接打开本机预览地址（`http://<局域网IP>:8787/#h=<自动填充配置>`）。

## 网络接入方式

桌面网关只监听本机端口，需要一种方式让外部网络到达它：

### 方式一：局域网直连（默认可用）

同一 Wi-Fi 下，手机扫码或直接访问设置页显示的地址：

```
http://<桌面机局域网 IP>:8787
```

Windows 首次开启网关时系统会弹防火墙授权，需允许。

### 方式二：内置 Cloudflare 快速隧道（设置页一键，推荐）

设置 → 远程访问 → 「公网访问」→ 开启：应用自动拉起 cloudflared（本机没有时可一键下载，
走 GitHub Releases + sha256 校验后装到应用数据目录），换到一个临时公网地址
（形如 `https://random-words.trycloudflare.com`），并把它作为二维码与地址列表的首选入口——
手机不在同一网络也能扫码直连。

- 免费、**不需要 Cloudflare 账号**（TryCloudflare 快速隧道）；
- 公网侧是 HTTPS/WSS（TLS 在 Cloudflare 边缘终结，回源到本机回环是明文 HTTP/WS）；
- **地址每次启动都会变化**；停止网关或切换绑定模式会联动收掉隧道（避免留下 502 幽灵地址）；
- 失败时设置页直接给出错误与 cloudflared 日志尾巴；固定域名请用下面的命名隧道；
- 二进制解析顺序：设置页指定的路径 → PATH → 常见安装位置（/opt/homebrew/bin、/usr/local/bin）
  → 应用数据目录 `bin/cloudflared`。

### 方式三：手动 Cloudflare Tunnel（命名隧道 / 固定域名）

内置隧道只提供临时地址；需要固定域名时，自行创建命名隧道：

```bash
cloudflared tunnel login
cloudflared tunnel create kova
cloudflared tunnel route dns kova kova.example.com
cloudflared tunnel run --url http://localhost:8787 kova
```

也可临时手动跑快速隧道（等价于内置开关，只是不集成二维码/地址联动）：

```bash
cloudflared tunnel --url http://localhost:8787
```

> 注意：https 页面下 WS 自动使用 `wss://`。TLS 在 Cloudflare 边缘终结，回源到本机是明文 HTTP/WS。
> 用内置隧道时无需手工输入地址——二维码与地址列表会自动采用它。

### 方式四：Tailscale（免暴露公网）

桌面与访问设备登录同一 Tailscale 账号后，访问：

```
http://<桌面机的 Tailscale IP>:8787
```

流量走 WireGuard 加密，不经公网，适合个人多设备使用。

### 其他 WS 客户端

非浏览器的 WS 客户端直连 `ws://<IP>:8787/ws`，协议见 `apps/electron/main/remote.ts` 头部注释。

## 安全须知

- **网页端具备你桌面端助手的对话与文件操作能力**，请勿把地址、配对码、token 泄露给不信任的人。
- 配对码只存在内存中，重启网关/应用后自动失效。
- token 在桌面端 SQLite 中**加密落盘**（kv 表，键 `remote.token`）；设置页「撤销所有设备」或网关关闭可使所有已配对设备失效。
- **管理面消息在网关一律拒绝**（仅限桌面端）：凭据/AI 服务、MCP、技能、子代理、记忆与个性化、模型属性、自动化等；远程只保留会话/聊天类操作。API Key 从协议层就不再回传网页端（只回掩码）。拒绝按**请求级错误**回帧（带原请求 id + `error.code="REMOTE_DENIED"`），表现为该次操作提示"该操作仅限桌面端"，不影响连接本身。
- 绑定模式可在设置页关闭「局域网访问」：网关改绑 `127.0.0.1`，仅本机可连（配隧道/Tailscale 时用）。
- **快速隧道只在设置页显式开启后才建立**，停止网关/切换绑定模式会联动收掉；公网地址是随机临时域名，
  但知道地址的人仍需配对码才能接入——地址与配对码都不要外泄。
- 网关关闭后所有远程连接立即断开。
- 局域网 HTTP 为明文，敏感环境建议走 Tailscale 或隧道（TLS）。
- 远程新会话落在本机用户主目录，不支持工作区目录选择。
- 中断（abort）是全局的：网页端中断会同时打断桌面端正在进行的回复，反之亦然。

## 远程网页端的功能边界

| 功能 | 可用性 |
|---|---|
| 流式聊天 / 中断 | ✅ |
| 会话列表 / 历史回放 / 重命名 / 删除 | ✅ |
| 模型与技能设置 | ❌（网关拒绝管理类消息，桌面端专属） |
| 凭据 / API Key | ❌（协议只回掩码，管理消息被网关拒绝） |
| 工作区目录选择 | ❌（远程新会话使用桌面端用户主目录） |

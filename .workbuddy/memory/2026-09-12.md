# 2026-09-12

## 修复：Tailwind v4 shadow 工具类全局失效

**现象**：`shadow-sm` / `shadow-md` / `shadow-lg` 等写了没效果，`shadow-none` 和任意值 `shadow-[...]` 正常。

**根因**：`app/styles/globals.css` 第二个 `@theme inline` 块里，7 个 token 被硬编码置空：

```
--shadow-2xs/xs/sm/md/lg/xl/2xl: 0 0 #0000;
```

`0 0 #0000` = 偏移 0 + 模糊 0 + 透明色，等于没有阴影。

**关键点**：因为是 `@theme inline`，工具类会**内联**这个值而不是引用 `var(--shadow-md)`，
所以在 `:root` / `.dark` 里补 `--shadow-*` 也救不回来。要让 inline token 运行时可切换，
必须内联一个变量引用：`--shadow-md: var(--app-shadow-md)`。

**处理**：删掉那 7 行，让 Tailwind 默认 shadow scale 生效。依据是把 shadcn registry 查清楚了：
- `https://ui.shadcn.com/r/styles/base-vega/index.json` → `cssVars: {}`，只有 `@apply border-border` 和 body 两条
- `https://ui.shadcn.com/r/colors/neutral.json`（项目 `:root` 那套 oklch 值的来源）→ 只有颜色 + `--radius: 0.625rem`

即 shadcn 当前根本不定义 `--shadow-*`，那 7 行是早期 shadcn v4 扁平化主题的遗留。跟 shadcn 对齐 = 不覆盖。

**验证方法**（项目没装 tailwind CLI，用 postcss 直出），临时脚本用完即删：

```js
import postcss from "postcss";
import tailwind from "@tailwindcss/postcss";
const css = `@import "./globals.css";\n@source inline("shadow-sm shadow-md shadow-lg");`;
postcss([tailwind()]).process(css, { from: "<project>/app/styles/__probe.css" });
```

删改后产物确认 `--tw-shadow` 已带真实值（如 `0 1px 3px 0 rgb(0 0 0 / 0.1)`）。

## 遗留问题

1. 两个 `@theme inline` 块（25-124 / 126-189 行）大面积重复，且 **radius 互相打架**：
   前者 `calc(var(--radius) * 0.6)`，后者 `calc(var(--radius) - 4px)`，后者生效。建议合并。
2. 深色模式下 Tailwind 默认那套 10% 黑影压不住深底（shadcn 本体也这样，主要靠 border/ring）。
   若要深色可见，需要加 `--app-shadow-*` 间接层并在 `.dark` 加重。
3. 复原后如果觉得整体太"浮"，优先调组件类名（`shadow-lg`→`shadow-md`）而不是改 token。

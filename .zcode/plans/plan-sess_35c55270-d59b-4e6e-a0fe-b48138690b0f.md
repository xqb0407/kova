## 问题确认（都是真的）

1. **哨兵泄漏（真 bug，已定位）**：`thread_snapshot`（sidecar `handlers/sessions.ts:310-334`）是 react-pi 迁移后的新契约，把转录原生 agent 行**直出**给前端（不过 `historyToUiMessages` 的哨兵过滤）；桌面 `projectPiThreadMessages` 的 `case "user"` 分支（`messageProjection.ts:549-564`）无任何过滤直接渲染气泡 → 你在聊天气泡里看到了 `[[auto-continue]]`。旧 `get_history` 路径是过滤的（`transcript.ts:527`），所以刷新走新契约就漏。
2. **预算耗尽静默中止（真缺口）**：3 次续跑用尽后 run 只打日志就以普通 `finish` 收尾（`stream.ts:193-195` + `prompt-pipeline.ts:697`），桌面当作正常完成，用户只看到「思考了很久然后没了」。
3. **反复截断根因**：模型把整个输出预算烧在 reasoning 上被切断（transcript 里 thinking 块内容完整，字段名是 `thinking`，早先「空块」是我脚本读错字段）；现有续跑消息不阻止模型再次长思考 → 今晚 4 连截断。

## 改动清单

**① packages/pi-protocol — 哨兵常量单源**
- `src/transcript.ts` 新增 `AUTO_CONTINUE_PREFIX = "[[auto-continue]] "` 与 `isAutoContinueText()`（经 index.ts 导出）；sidecar `sessions/transcript.ts:322` 改为引用共享常量。

**② sidecar — 堵 thread_snapshot 泄漏（根修复）**
- `thread_snapshot` 构建 messages 时跳过 `isAutoContinueText` 命中的 user 行；跳过前先做 ③ 的「最终中止」判定（需要看到相邻哨兵行）。

**③ sidecar — 预算耗尽可见信号（复刻 data-stopped 三路径同构）**
- live：`stream.ts` budget-exhausted 分支发 `{type:"data-truncation-stopped", id:"truncation-stopped", data:{}}`（此时 reqId 仍在 activeReqByThread）。
- 快照：`thread_snapshot` 对满足规则的行标注 `__truncationStopped: true`——规则：`assistant && stopReason==="length" && 无 toolCall && 下一条消息行不是哨兵续跑`（中途截断后面必跟哨兵，最终中止后面跟的是用户新消息或 EOF，天然区分）。
- 历史旧路径：`transcript.ts` `toUiMessage`/`historyToUiMessages` 对同规则行补同款 data part（仿 423-427 的 aborted 先例）。

**④ desktop — 投影消费与渲染**
- `messageProjection.ts` user 分支：防御性跳过 `isAutoContinueText` 命中行（从 pi-protocol 引入）。
- assistant 分支：`__truncationStopped` 行 → 等价 data part，与 live chunk 落下的 part 同形。
- 新增 `truncation-marker.tsx`（仿 `stopped-marker.tsx`）：检测 part → 渲染「连续输出截断，任务已中止」分隔线；`assistant-message.tsx:289` 旁挂载。

**⑤ sidecar — 续跑消息升级（降低循环概率）**
- `context.ts` `makeAutoContinueMessage(continues: number)`：第 2 次起追加指引「输出预算有限：不要再长篇思考，尽快输出正文或工具调用；大文件分多次写入」（仿 `prompt-pipeline.ts:115` TRUNCATED_TOOL_CALL_HINT 文风）。
- 调用点 `stream.ts:199`、`subagent/run.ts:313` 传入计数。

**⑥ 测试**
- sidecar：`auto-continue.test.ts` 补 escalation 断言；`transcript.test.ts` 补最终中止标记重建；thread_snapshot handler 补哨兵跳过 + 标注断言。
- desktop：`messageProjection.test.ts` 补哨兵 user 行跳过 + `__truncationStopped` 映射断言。
- 验证：`pnpm -C apps/sidecar/pi-agent test`、`pnpm -C apps/desktop test`（相关文件）。

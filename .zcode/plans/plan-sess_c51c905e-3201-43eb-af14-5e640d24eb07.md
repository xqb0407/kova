# 队列「并入」不可靠投递：修复计划（全在队列层，不动 question 工具）

## 根因（队列视角）

pill 的「并入」= `steerIntoActiveRun`（`protocol/prompt-pipeline.ts:206-246`）把消息交给 pi-core 内部 steering 队列（纯入队，`agent.js:184-185`），kova 队列条目即删除、客户端记「已并入当前回复」徽标。但 pi-core **只在模型调用边界消费**该队列（`agent-loop.js:84,107,113-118`），且 aborted assistant 会让 runLoop 直接终结不再轮询（145-157）。边界未到或注入后被中止时，sidecar 没有任何回收：`runTurnBody` 收尾从不检查 `agent.hasQueuedMessages()`，且全程只用 `agent.prompt()`（521/529），残留消息成孤儿——**并入操作没有「要么成功、要么回滚」的保证，失败即静默丢消息**（截图 2「已并入但一直没回复」；截图 1 的裸前缀是同一链路的展示缺陷）。

## 改动

**1. sidecar：并入的投递保证（prompt-pipeline.ts + sessions/prompt-queue.ts）——核心**

- **a. 入队即解边界阻塞（通用，非针对提问）**：`steerIntoActiveRun` 在 `agent.steer(...)` 之后，调用现成的解阻塞三件套 `clearPendingToolApprovals(run)` / `cancelPendingQuestions(threadId)` / `cancelPendingMcpApprovals(threadId)`（`abortRun` 已同款使用，均为幂等 no-op-safe），保证循环尽快抵达边界消费注入。取消语义「发起了新消息」与并入一致。
- **b. 轮末回收（保证不丢）**：`steerIntoActiveRun` 记录注入条目到 `run`（新增 `run.steerEntries: { reqId, cleanText, msg }[]`）；`runTurnBody` 的 finally 里逐条检查：条目仍在 `agent.steeringQueue`（未被边界消费）→ `drain` 清出；或已进转录但轮末没有任何 assistant 回应它 → 两种情形都把消息**去掉 `STEER_PREFIX` 前缀、重新入 kova 队列队首**（复用 enqueueTurn 引擎，`queue_update` 广播）→ pill 恢复显示该条，由既有队列接力泵在本轮链空出后自动派发 → 模型必然回应。「并入失败自动降级为排队」对用户可感、不自相矛盾。
- **c. 客户端徽标一致性（prompt-queue-bar / usePiQueue）**：`queue_update` 快照中重新出现的条目文本若命中「已并入当前回复」徽标账本，清除对应徽标（回收后状态回到排队中）。

**2. sidecar：直播气泡归一化（wireSessionEvents 的 message_start 桥接处，thread-events.ts）**：user 消息以 `STEER_PREFIX` 开头 → 发出前剥离前缀并附加与历史重建 `userUiParts`（transcript.ts:348-388）同形的 `data-steeredNote` part，直播渲染与刷新后一致（徽标渲染组件已有，复用）。顺带删 `{type:"data-steered"}` 死帧（prompt-pipeline.ts:233，新客户端链 prefilter 即丢）。

**3. 客户端：收尾自愈（pi-client-base.ts:576-580）**：inflight reqId 的 finish/error 帧触发的 `refreshNow` 改 force=true——收尾帧后必拿并派发一次权威快照，杜绝 live 事件缺失时转圈/停止键永挂。

## 验证

- `bun test`（sidecar + desktop 全套）+ `./node_modules/.bin/tsc --noEmit`（apps/desktop；他人在途的 flatMap 两处报错不碰）；为回收逻辑补单测：注入未消费→轮末重入队且剥前缀、已回应→不回收。
- 人工复现（即截图 2 场景）：① 运行中 Enter 发第二条 → pill 出现；② 模型卡在提问/长任务时点「并入」→ 数秒内模型按注入内容回应（解阻塞生效）；③ 点「并入」后立刻按停止 → pill 该条自动回队、「已并入」徽标消失、轮次结束后自动派发并回应（回收生效，不再静默丢）；④ 直播注入气泡无 `[[queued-steer]]` 前缀、带徽标，刷新后一致；⑤ 并入/中止后转圈停止、恢复发送态（force 快照兜底）。

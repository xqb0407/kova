## 本次新增（两处）
1. **标题超链接化**（read/edit/write 行）：
   - `components/assistant-ui/elements/tool-row.aui.tsx`：`ToolRowProps` 加 `primaryAsLink?: boolean`。primary 在 `primaryAsLink && onOpenPanel` 时渲染为可点 span：默认观感不变，悬浮出链接态（`hover:text-primary hover:underline underline-offset-2 decoration-1 cursor-pointer`）；点击 `stopPropagation + preventDefault → onOpenPanel()`（标题在 CollapsibleTrigger 内部，劫持点击不触发展开）。
   - `fileToolUI` 对 read/edit/write 传 `primaryAsLink={!!path}`；bash 不动。运行中无输出分支整行本就是开面板按钮，无需特判。
2. **写入/编辑行尾部 ±统计**（如截图 `+26` 绿色）：
   - `lib/panel-activity.ts`：把 `cachedFile` 里的 added/removed 计算抽成导出函数 `fileChangeStats(oldText: string | null, newText: string): { added, removed }`（cachedFile 改调它，单一实现；write=oldText null ⇒ added 为全文行数，edit=LCS diffLines 数 add/del）。
   - `tool-row.aui.tsx`：`ToolRowProps` 加 `stats?: { added: number; removed: number }`；secondary 之后渲染 `+{added}`（`text-emerald-600 dark:text-emerald-400`）与 `−{removed}`（仅 >0 时，`text-rose-500 dark:text-rose-400`），`font-mono text-xs tabular-nums shrink-0`；`fileToolUI` 在 `fileChangePair` 命中（edit/write）时传入。

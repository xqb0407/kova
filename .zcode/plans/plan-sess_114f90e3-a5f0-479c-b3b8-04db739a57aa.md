# Codex 桌面端风格右侧 Agent 面板

## 目标与形态
在聊天区右侧加一个可拖宽、可折叠的 Panel,风格对齐 Codex 桌面端:纵向活动流,自上而下三个区块——**计划**(任务清单)、**文件变更**(edit/write 的行级 diff)、**终端**(bash 命令与输出)。工具状态在面板关闭时以 Header 按钮角标提示。

## 数据来源(关键决策:零 sidecar 改动)
工具调用已经以 `tool-call` part(含 `args`/`result`/`status`)同时存在于实时流(stream.ts:122-145)和历史重建(transcript.ts:160-228)中,直接从 `useAuiState(s => s.thread.messages)` 派生面板内容;计划区复用现有 `lib/pi-todo.ts` 快照 store(`data-todo` chunk + `get_todo_state` 水合链路已就绪)。刷新、切线程、回溯历史都有数据,无需新增协议事件。

## 实施步骤

1. **引入 resizable 基础件**
   - `package.json` 安装 `react-resizable-panels`;新增 `components/ui/resizable.tsx`(shadcn 风格薄封装,Token 化样式)。

2. **派生层 `lib/panel-activity.ts`(新)**
   - `usePanelActivity()`:扫描当前线程 assistant 消息的 tool-call parts,按消息顺序产出
     - `terminal[]`:`bash` → {command, output, running, failed},failed 判定沿用 tool-fallback.aui.tsx:33 的 `[exit code: N]/[timeout]` 正则;
     - `files[]`:按 `file_path` 聚合 `edit`/`write`(含 read 不算),每文件保留逐次变更条目 + 累计 `+N/-M`;
   - `diffLines(oldText,newText)`:LCS 行级 diff(>400 行截断退化为新旧分块),供文件区红绿渲染。

3. **面板组件 `components/agent-thread/agent-panel/`(新,4 个文件)**
   - `index.tsx`:面板骨架——Header(标题、运行中转圈/shimmer 状态行、折叠按钮)+ 滚动区,依次渲染三个区块;`framer-motion` 宽度展开/收起动画;窄屏(<md)改为 `fixed` 右缘浮层;
   - `plan-section.tsx`:从 `todo-panel.tsx` 迁移 `fetchTodoState` 水合与 `TodoList` 复用逻辑(去掉 composer 浮层特有的药丸/关闭态,面板折叠即隐藏);空清单不渲染区块;
   - `files-section.tsx`:每文件一张可折叠卡(路径 + `+N -M` 徽标 + 状态点),展开显示逐次 diff(编辑绿/红行、write 全增);
   - `terminal-section.tsx`:每条命令一张可折叠卡(mono 命令行、运行中 spinner、失败红点),展开显示 `pre` 输出(沿用 ToolFallback 的 max-h + overflow 样式基调)。

4. **布局接线 `components/agent-thread/base.tsx`**
   - `<main>` 内改为 `ResizablePanelGroup(horizontal)`:聊天 `Thread` flex 面板 + `PanelResizeHandle` + 面板(默认约 400px,`collapsible`,`autoSaveId` 记忆宽度);
   - `panelOpen` state + localStorage 持久化,传给 Header 与面板;窗口过窄自动不占位。

5. **Header 开关 `components/agent-thread/header.tsx`**
   - 分享按钮左侧加 `PanelRightIcon` 切换按钮;面板收起且有未完成计划/运行中工具时显示小圆点角标。

6. **TodoPanel 归位**
   - `composer.tsx` 移除 `<TodoPanel />` 挂载;删除 `todo-panel.tsx`(逻辑并入 plan-section);`lib/pi-todo.ts` 不动。

## 验证
- `npx tsc --noEmit` 通过;`npm run dev` 下跑一个真实任务:面板实时出现 bash/edit 条目、运行中动画、计划勾选更新;
- 折叠/展开、拖动宽度、刷新页面后宽度与开合状态保持;切线程后面板随 `threadId` 切换数据;打开历史会话确认文件/终端区块由转录重建数据渲染;
- 深浅两套主题下检查对比度。

## 取舍说明
- 文件 diff 用前端行级算法展示 old/new 变更,不接 git/不落盘读原文件(改动最小、离线可靠);
- 工具活动只收录 bash/edit/write(read/glob/grep/web 属查询噪音,与 Codex 面板行为一致);
- 计划区改为"面板折叠即隐藏",不再保留 composer 药丸入口。

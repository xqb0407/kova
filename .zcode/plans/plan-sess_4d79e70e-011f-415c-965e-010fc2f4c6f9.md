## 实现方案：todo 任务清单（rpiv-todo 逻辑 + 项目现成 TodoList 渲染）

**工具语义与状态溯源全部照搬 rpiv-todo**（同为 pi-agent-core，行为对齐）：单 `todo` 工具、六 action（create/update/list/get/delete/clear）、Task{id, subject, description?, activeForm?, status, blockedBy?, owner?, metadata?}、4 态迁移表（pending↔in_progress→completed，deleted 墓碑终态）、依赖图校验（悬空/墓碑/自环/成环拒绝，错误带内返回）、no-op 检测（防模型重复发同一 update）。**持久化走事件溯源**：每次成功调用把变更后的全量快照放进 toolResult `details`（transcript 行已支持 details 字段），重启/压缩后从转录回放最后一个快照重建清单——零额外落盘。

**UI 直接复用项目里现成但零引用的 `components/custom-ui/todo-list.tsx`**（framer-motion 动效、计数滚动、划线、全完成自动折叠都是它自带的），只补一层数据管道 + 薄容器。

### Sidecar（2 新文件 + 4 处接线）

1. **`sidecar/pi-agent/src/todo-state.ts`（新，纯逻辑移植）**：`tool/types.ts`（Task 等类型 + TypeBox schema 全文，`StringEnum` 同版 pi-ai 可用）、`state/invariants.ts`（迁移表）、`state/task-graph.ts`（detectCycle/deriveBlocks）、`state/state-reducer.ts`（applyTaskMutation 全量移植，错误文案原样保留）、`tool/response-envelope.ts`（content 人话摘要 + details 快照）。
2. **`sidecar/pi-agent/src/todo.ts`（新，注册层，仿 question-tools.ts）**：模块级 `todoStates: Map<threadId, TaskState>`（会话隔离=rpiv 的 per-session slot）；`buildTodoTool(threadId)`：execute → applyTaskMutation 提交 → `sendEventChunk({type:"data-todo", data:{tasks, nextId}})` 推面板 → 返回快照 envelope；`replayTodoFromMessages(threadId, messages)`：扫 `toolResult.toolName==="todo"` 的转录行取末个快照回填。rpiv 的 8 条 promptGuidelines 精简并进 `tools.ts` SYSTEM_PROMPT_CORE 新段。
3. **接线**：`tools.ts` buildTools 挂 todo；`modes.ts` toolsForMode 里 todo 归 agent 模式（plan/goal 已有 SubmitPlan/Goal 契约，delegate 工具集排除 todo 防子代理串写父清单）；`sessions.ts` resolveSession 恢复分支调回放；`protocol.ts` + `lib/pi-bridge.ts` 新命令 `get_todo_state {threadId}` → 回 `{type:"todo_state", tasks, nextId}`（切线程/刷新时水合面板用）。

### 前端（1 store + 1 薄容器，渲染全用现成 TodoList）

4. **`lib/pi-todo.ts`（新）**：照 pi-session-mode.ts 的 per-thread store——`applyTodoChunk` + `useThreadTodos(threadId)` + `fetchTodoState`（get_todo_state）；`pi-transport.ts` transform 拦 `data-todo`（同 data-planningState 形态，不进消息流）。
5. **`components/agent-thread/todo-panel.tsx`（新，薄壳）**：订阅 store → Task[]→TodoItem[] 映射（过滤 deleted 墓碑；in_progress 标题用 activeForm 回落 subject；`detail` 位放 `⛓ #1,#2` 阻塞标记；`progress` 不接）→ `<TodoList items title={Todos}>`；空清单不渲染；挂在 composer.tsx 的 PlanApprovalCard 同层。

### 有意不搬（终端专属）

`/todos` 命令（面板常驻）、overlay 行数预算截断、i18n bridge / config.json、ctrl+shift+t（TodoList 自带折叠头，点标题即折叠；「全完成自动折叠」= collapseOnComplete 原生行为）。

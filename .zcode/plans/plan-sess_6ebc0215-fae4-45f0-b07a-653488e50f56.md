# "项目"页面重构计划（代码结构为主 + 三处入选微调）

## 背景与原则

重构对象：侧边栏"项目"入口对应页面（`components/agent-thread/base.tsx:712` → `ProjectsView`，视图在 `components/projects/` 共 9 文件 2655 行，数据层 `lib/project/*`）。
用户确认：**只动代码、整体视觉保持现状**；三个微调点入选（列表页、工作台顶栏、tab 统一口径）。除下列明确列出的微调外，所有改动做到像素级不变。数据层 store 行为与测试不动，sidecar 不动。

## 一、共享件抽取与去重（视觉零变化）

**1. 任务展示共用件 → 新文件 `components/projects/task-display.tsx`**
从 `project-board.tsx` 与 `project-task-list.tsx` 抽出逐字重复的渲染：
- `TaskResultBlock`（结果块含 failed 红色调）、`TaskArtifacts`（产出文件条）——两文件 class 相同
- `TaskStatusActions`：退回/完成/失败三按钮，用 `variant: "text" | "icon"` 一个组件两种渲染（看板带字小按钮、清单 icon 按钮，各保持现状外观），可见性规则单点维护
- `STATUS_DOT`/`STATUS_CHIP` 色板、`publisherText(task)`、`fmtShortTime(ts)` 收拢；看板专属的 `COLUMNS`/`COLUMN_HINT` 留在原文件

**2. `ProjectMemberAvatar` 搬家 → 新文件 `components/projects/project-member-avatar.tsx`**
现定义在邀请弹窗里却被另外两个组件跨文件引用；迁出并更新三处 import。

**3. 订阅样板收拢 → 新文件 `lib/project/use-project-live.ts`**
activity 与 tasks-tab 各自手写"refresh 一次 + watchProjectXxxChanges + cancelled 清理"effect（activity 写两遍）。抽 `useProjectLive(projectId, { chat, tasks })`，保持 StrictMode 语义。

**4. 子智能体名字索引 → 新文件 `lib/subagent/use-subagents-by-name.ts`**
三处各自建 Map、两处重复定义 `norm()`；抽 `useSubagentsByName(cwd)` 返回 `{ agents, byName }`。

## 二、状态机与文件拆分（视觉零变化）

**5. 删除 `reloadKey` 绕圈刷新**：store 的 mutate 应答即新清单，创建/注销/邀请/存指令后无需手动 refresh。移除 `reloadKey` state 与 effect（挂载刷新保留）；`ProjectDetail`→`config-panel`/`invite-dialog` 的 `onChanged` 透传链整体删掉。

**6. 拆分 `projects-view.tsx`（493 行 → 薄壳约 150 行）**：新文件 `create-project-dialog.tsx`、`delete-project-dialog.tsx`、`project-card.tsx`（CardShell + ProjectGlyph + addedAgo + 卡片）；模板区留在视图文件。

**7. 统一错误/提示横幅 → 新文件 `components/projects/project-banners.tsx`**：`ErrorBanner`/`NoticeBanner`，各处显式传现状 class 组合保持外观；唯一有意差异是 tasks tab 错误条字号对齐其他 tab（`text-sm`→`text-xs`，入选微调）。

**8. 口径统一**：tasks tab 错误文本过 `describeLoadError`（补"sidecar 版本落后"提示）；activity 发送失败 `toast.error` → `toast.add({type:"error"})` 与全目录一致。

## 三、入选微调（按现有样式语言实现，改动范围仅此三条）

**9. 工作台顶栏（project-detail.tsx）**：面包屑右侧加成员头像摘要（最多 5 个 size-6 圆头像叠放 + `+N`，点击打开邀请弹窗，无成员不渲染）；新文件 `lib/project/project-ui-prefs.ts` 仿 `ui-prefs.ts` 的 localStorage 口径，按 projectId 记住 tab 与配置栏开合（默认仍"动态+展开"）。

**10. 项目列表页（projects-view.tsx）**：加载态文字"载入中…"换成 6 张骨架卡（复用现成 `components/ui/skeleton.tsx`，按卡片结构排版）；搜索非空时隐藏"从模板创建"整块。

**11. tab 工具行**：三个 tab 的 44px 工具行统一为动态 tab 的 `h-11 px-6` 基准（任务/资产行若因此有 2-4px 间距变化即入选的"统一 toolbar 行样式"）；刷新/搜索控件保持行尾右侧。

## 四、明确不做

不改 `lib/project/*.ts` store 行为、不动 sidecar、不动 base.tsx 接线；不做拖拽看板、不改信息架构、不动配色/圆角/字体 token。

## 五、实施顺序

新文件（avatar/task-display/hooks/banners/prefs）→ board/list/tasks-tab/activity 接共用件 → 拆 projects-view + 删 reloadKey/onChanged 链 → config-panel/invite-dialog 接线 → 三项微调 → 全目录 grep 旧引用清零。

## 六、验证

- `bun run --filter desktop build`（typecheck + 编译必须通过）
- `cd apps/desktop && bun test lib/project`（三个 store 测试仍全绿）
- `dev` 手动走一遍全流程（列表→建项目→工作台三 tab→邀请→改指令→重进验证 tab 记忆→搜索→注销），确认除第 7/9/10/11 条列明的微调点外无视觉 diff
- 结束时报告改动文件清单与每个微调点说明

侧边栏批量归档 + 右键菜单补齐 + 任务已读/未读

## 需求拆解
1. **右键 contextmenu 补齐**（参考图，划线项不做）：标记为未读/已读、在 Finder 中打开、复制路径、复制会话 ID、查看调用轨迹。现有项（重命名、分支对话、归档/取消归档、删除）保留。
2. **任务已读/未读状态**：菜单可标记未读；行内未读标识；切到该会话自动已读；后台会话回复完成自动置未读。
3. **批量勾选归档**：侧边栏「任务/项目」两个 tab 统一的批量模式——勾选跨 tab 保留，一次归档多条。

## 新增文件
- `lib/pi/pi-unread-sessions.ts`：未读集合 store，镜像 pi-pinned-sessions 模式（localStorage 键 `pi.unread-sessions`，键 = thread item id = remoteId，新链路两者同值）。
- `lib/pi/pi-thread-batch.ts`：批量模式 ephemeral store（active 标志 + selected Set + 当前 tab 可见 id 集），useSyncExternalStore 订阅，不持久化。

## 修改文件
- `components/assistant-ui/elements/thread-list.aui.tsx`：
  - `ThreadListItemMore` 按参考图顺序补菜单项：标记为未读/已读（仅已落盘会话，remoteId 有值）；在 Finder 中打开 + 复制路径（仅 Tauri；路径解析——任务会话 = 任务工作区会话子目录 `taskWorkspaceSessionDir(remoteId)`，项目会话 = 其 workspacePath；用现成 `fsReveal(cwd, path)`）；复制会话 ID（remoteId，navigator.clipboard）；查看调用轨迹（`openPanelTab("trace", { sessionId: remoteId })` + `agent-panel:open` 事件，与 header 同款）。
  - `ThreadListItem`：未读时行首（loader 槽位，pinned/running 让位）渲染小圆点 + 标题 font-medium；批量模式下行首换勾选框、点击行切换选中（不激活会话）。
  - 任务列表与项目列表组件：批量模式接线 + 把当前渲染的会话 id 注册进 batch store（供「全选」用）。
  - 新增 `ThreadUnreadTracker` 效果组件（挂 ThreadListRoot 内）：mainThreadId 变化 → markRead；订阅 agent-events 的 `agent.turn.completed`（threadId ≠ 当前主线程）→ markUnread。
- `components/agent-thread/clone-thread-shell.tsx`：tabs 行（桌面 + 移动两处）加「批量管理」切换按钮；批量模式下该行换成操作栏：已选 n 项 · 全选（当前 tab 可见项）· 归档(n) · 退出。归档动作：过滤 status==="regular"（跳过未落盘）→ 逐条 `aui.threads.item({id}).archive()`（当前打开中的会话 core 自动先切走）→ toast 汇总 → 清空并退出批量模式。

## 行为口径
- 未读键空间与 agent 事件一致（threadId = remoteId）；草稿（status "new"）不可标记未读/不可被批量归档。
- 批量选择跨 tab 保留（统一集合），退出批量模式清空。
- 远程/浏览器模式：Finder/复制路径两项隐藏（isTauri gate），其余功能可用。

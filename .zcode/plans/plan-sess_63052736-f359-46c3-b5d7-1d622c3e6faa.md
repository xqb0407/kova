# pageshare：静态页分享服务（Go + 管理 UI，v1）

## 目标
独立项目（**不在 ai-teamplte 仓库内**，新建于 `/Users/herther/Desktop/pageshare/`，独立 git 仓库）。AI 生成的静态页面（多文件站点）上传到公网可达的服务，服务转存 **S3/R2 私有桶**并生成分享链接。功能：覆盖更新、吊销删除、有效期 TTL、访问密码，**外加内嵌管理 UI**。agent 侧插件后续再做，API 按方便脚本调用设计。

## 架构
```
浏览器管理页 /admin ──┐
agent/脚本 ───────────┼─tar.gz 或 zip─▶ Go 服务（公网，Caddy/Nginx 反代 TLS）
                      ▼                 ├─ 元数据 SQLite
                                        └─ S3/R2 私有桶（aws-sdk-go-v2，兼容 R2/MinIO）
访客 ──GET /s/{id}/path──▶ 服务：TTL/密码校验
        ├─ 无密码站点：302 → presigned URL（不吃服务带宽）
        └─ 有密码站点：服务代理流式回源（口令门 + HMAC 签名 cookie 会话）
```
桶保持私有，凭据只在服务侧。Storage 接口按 `Put / Get / Presign / DeletePrefix` 设计，s3 实现之外提供 mem 实现供测试与本地冒烟。

## 管理 UI（go:embed 内嵌，单二进制自带）
- 技术栈：Vite + React + TS + Tailwind v4（`frontend/`），构建产物由 Go `go:embed` 内嵌；未构建时提交占位页，保证纯 `go build` 可过
- **视觉体系直接沿用 slide-canvas 的 "Wise" 主题**（从该插件拷贝令牌层与组件原语）：
  - `index.css` 令牌层：暖白纸面 `#f6f7f2` + 近黑 `#0e0f0c` 文字 + 亮绿 `#9fe870` CTA（绿底字用深绿 `#163300`）、发丝线边框、圆角语言（lg=12/xl=16、浮卡 20-24、按钮药丸）、磨砂玻璃 `--glass` 配方；light/dark 双态 `data-theme` 驱动（管理页无宿主桥，用系统偏好初始化 + 手动切换按钮）
  - 组件原语：shadcn new-york 风格（Radix + cva + tailwind-merge），拷贝 slide-canvas 的 `components/ui/`（button/dialog/dropdown-menu/input/label/select/tooltip/scroll-area 等）与 `lib/utils`；图标 lucide-react
  - 丢弃画布专用令牌（`--sc-*`、`--artboard-shadow`）
- 页面（单页）：token 登录（存 localStorage）→ 站点列表卡片（名称、分享链接复制、创建/更新时间、TTL 倒计时、密码角标）→ 拖拽文件夹/文件上传（前端 fflate 打 zip → POST，可填 name/ttl/password）→ 操作：打开链接、覆盖上传、删除（二次确认 dialog）
- `bun run build` 出静态产物；`tsc --noEmit` typecheck

## API
管理面（Bearer token，constant-time 比较）：
- `POST /api/v1/sites` — 建站+上传。body：tar.gz 或 zip；form 字段 `name`、`ttl`（如 `72h`）、`password`（均可选）→ `201 {id, url, version, expires_at}`
- `PUT /api/v1/sites/{id}` — 覆盖发布新版本，URL 不变，旧版本对象清除
- `GET /api/v1/sites`、`GET /api/v1/sites/{id}`、`DELETE /api/v1/sites/{id}`（吊销）
- `GET /healthz`

公开面：
- `GET /s/{id}/` → 入口 index.html（无斜杠 301 补齐）
- `GET /s/{id}/{path...}` → 302 presigned 或代理回源，Content-Type 按扩展名
- `GET/POST /s/{id}/gate` — 密码页，通过后发签名 cookie

## 数据模型（modernc.org/sqlite，纯 Go 无 cgo）
- `sites(id 8位crockford主键, name, password_hash bcrypt可空, created_at, updated_at, expires_at可空, deleted_at, current_version, entry)`
- `versions(site_id, version, created_at, file_count, total_bytes)`

## 上传安全
zip-slip/tar 路径清洗（拒绝 `..`、绝对路径、符号链接）；压缩体 ≤100MB、文件数 ≤2000、解压总量 ≤500MB 流式限额；Content-Type 按扩展名写入对象元数据。

## 验证方式
- `go vet ./...` + `go test ./...` 全绿（zip-slip、密码、TTL 用例）；前端 `tsc --noEmit` 通过
- `go build` 出单二进制，`bun run build` 出 UI 产物
- httptest 端到端：上传 zip → /s/ 得 index.html → 覆盖更新生效 → 设密码无 cookie 得口令页 → DELETE 后 404
- 本地起服务打开 /admin 完整走一遍：上传/复制链接/删除（mem 存储）
- 可选：提供 R2/S3 测试凭据则真实桶冒烟

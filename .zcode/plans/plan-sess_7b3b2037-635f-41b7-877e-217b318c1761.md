# 画布插件新增 embed（内嵌网页）与 svg（源码内嵌）元素

参考 tldraw/Excalidraw/Miro 的 embed 模式，给 slide-canvas 插件加两种新元素类型，解决「agent 生成 SVG 插上画布」和「内嵌网页渲染」两个诉求。

## 核心结论（调研发现）

- 面板是 `blob:` iframe + `sandbox="allow-scripts"`（不透明源），宿主 CSP `frame-src 'self' data: blob:` **不含 https:**——内嵌网页必须放开这一行（宿主唯一必改点）
- 沙箱标志被嵌套 iframe 继承：嵌入页拿不到 Cookie/登录态（YouTube 基础播放可用，需登录内容降级）——独立 dev 模式（浏览器直开）无此限制
- 面板无网络能力：URL→embed 地址解析用客户端正则表（tldraw 同款做法），无 oEmbed
- 命中测试纯几何，新元素自动参与框选/拖拽；iframe 吞指针事件用「双击激活交互」浮层解决
- svg 元素完全复用 mermaid 管线（源码→data-url→`<img>`/光栅化 image fill→`svgToPng` 导出）
- 已知坑（mermaid.ts 注释）：WKWebView 下 `<img>` 加载含 foreignObject 的 SVG 会失败 → 需错误兜底 UI

## 改动清单

### 1. 宿主（apps/desktop）
- `src-tauri/tauri.conf.json`：CSP `frame-src 'self' data: blob: https:`（一行）。connect-src/media-src 保持锁定，嵌入页仍被 `allow-scripts` 沙箱隔离，安全面最小化

### 2. 插件 schema（ui/src/doc.ts）
- `El` 联合类型加 `EmbedEl | SvgEl`：
  - `{ kind:"embed", url /* 必填 http/https */, title? , ...共有几何 }`
  - `{ kind:"svg", code /* 必填 <svg>…</svg> 源码 */, ...共有几何 }`
- `parseEl` 按既有容错模式各加一个分支（id 前缀 `em-` / `sv-`）
- 默认尺寸：embed 640×400，svg 480×360

### 3. embed 地址解析（新文件 ui/src/providers.ts）
- 纯函数 `resolveEmbed(url) → { provider, embedUrl } | { provider:"generic", embedUrl }`
- 白名单正则表：YouTube/youtu.be/shorts、Bilibili(BV→player.bilibili.com)、Vimeo、Google Maps(output=embed)、Spotify(/embed/)、CodePen(/embed/)、CodeSandbox(/embed/)、Figma+FigJam(figma.com/embed?url=)、Excalidraw；未命中 → 原样 iframe 兜底（被 X-Frame-Options 拒的站点显示浏览器拒绝页 + URL 徽标）

### 4. 渲染（ui/src/render.tsx + leafer 轨）
- **SvgElView**（DOM 轨）：`<img src=data:image/svg+xml,…>` + objectFit + onerror 兜底（提示「可能含 foreignObject，画布轨不支持」）
- **EmbedElView**（DOM 轨）：`<iframe sandbox="allow-scripts allow-same-origin allow-popups allow-forms" allow="fullscreen; autoplay" loading="lazy">` + 未激活时透明浮层盖住 iframe（画布平移/框选不受影响）；双击激活 → 浮层放行、显示「Esc 退出交互」角标；被拖拽时（liveMap 命中）切成 ghost 占位避免 iframe 重绘卡顿
- **Leafer 轨**：`scene.ts` svg → 复用 mermaidMap 模式（LeaferStage 加 svgMap：svgToPng 透明底光栅化 → image fill）；embed → 画占位框；真实 iframe 由 CanvasStage 新增的 **DOM 浮层**（视口 transform，同钢笔预览层模式）在两种轨道下统一渲染

### 5. 交互入口（ui/src/CanvasStage.tsx + App.tsx）
- `onPaste` 加文本分支：剪贴板是 http(s) URL → 落点创建 embed（Miro/tldraw 式贴链接即嵌入）
- 工具栏加「网页」入口（快捷键 E）→ 插入 embed 并弹 URL 编辑；右键菜单同理
- 双击编辑：沿用 mermaid 的 editingId 机制扩展到 embed（改 URL）与 svg（改源码）

### 6. 导出（ui/src/export.ts + export-svg.ts）
- **pptx**：svg → `svgToPng` 贴图（复用 mermaid/draw 路径）；embed → 圆角占位框 + provider 名 + URL 文本（pptxgenjs `hyperlink` 放超链接，放映可点击）
- **SVG 导出**：svg → `<image href=data-url>` 内嵌（保矢量、天然沙箱化）；embed → `<a href>` 包矩形 + URL 文本
- **HTML 导出**：svg 同上；embed → 真活 `<iframe sandbox>`（浏览器打开即可交互）

### 7. 文档（plugins/slide-canvas/skills/slides/SKILL.md）
- 两种新 kind 的 schema、agent 工作流（SVG 源码直接内嵌进 JSON，不再需要写资产文件）、已知限制（嵌入页无 Cookie/登录态、pptx 里 embed 是链接占位、foreignObject 限制）、贴 URL 即嵌的 UX 说明

## 验证

- `pnpm --filter slide-canvas typecheck` + `build`（重建 canvas.html 单文件）
- providers.ts 纯函数用 node 脚本跑断言（正则表各 provider + 兜底）
- 沿用 `.zcode/tmp/e2e-slide-canvas` 的 Playwright standalone 截图方式：DOM 轨渲染 embed（YouTube 白名单项 + 任意 URL 兜底）与 svg 元素、双击激活交互、导出三种产物的目视检查
- 桌面端真机验证 CSP 放行后 iframe 可加载（走 dev preview）

## 明确不做（v1）

- 视频文件元素（media-src 未放行 https，工作区视频走 data-url 体积大，后续再说）
- HTML 片段内嵌（安全面大，无专业白板先例）
- 服务端取链接标题/缩略图（面板与桥均无网络能力）

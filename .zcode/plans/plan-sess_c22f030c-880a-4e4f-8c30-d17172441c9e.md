## 目标

把内置浏览器面板升级成截图里的「DevTools 式检查器」：**点选元素 → 右侧组件树 + 设计/CSS 属性面板**、**底部控制台日志 + 错误计数 + 添加到对话**、**视口数值/缩放精确控制**。按你确认的范围：**第一期做人用检查器 UI**，**第二期把同一批宿主原语暴露成 4 个 `browser_*` agent 工具**，**控制台接受页面级降级**。

## 架构决策（关键）

wry/WKWebView 没有「页面 → 宿主」的推送通道，页面产生的事件（选中元素、console 输出）只能由宿主 `eval_with_callback` 主动拉取。所以采用**前端轮询宿主命令**模型，与现有 `eval_json`/`current_page` 一致：

- 选中元素：前端开 inspect 模式 → 注入覆盖层脚本把选中节点写进 `window.__xrInspectSelection` → 前端每 ~400ms 调 `browser_inspect_poll` 取走并清空。
- 控制台：webview 创建时注入 `CONSOLE_INIT_JS` 钩住 `console.*` + `window.onerror` + `unhandledrejection` + `fetch/XHR` 包装，写进 `window.__xrConsole` 环形缓冲（上限 200）→ 前端每 ~1s 调 `browser_console_get` 增量读取。
- 轮询仅在浏览器 tab 激活且面板可见时运行（复用现有 `hiddenRef`/`url` 状态），收起即停。

## 第一期：人用检查器

### 1. `src-tauri/src/browser_scripts.rs`（新增注入脚本，沿用 IIFE+try/catch 返 JSON 模式）
- `INSPECT_JS(enabled)`：开启时挂 `mousemove`（`elementFromPoint` → 绿色描边覆盖层 + `div` 角标）、`click`（`preventDefault` → 锁定选中、写入 `__xrInspectSelection`）；关闭时移除监听与覆盖层。
- `INSPECT_POLL_JS`：返回并清空 `__xrInspectSelection`，序列化成描述符：`{ tag, id, classes, cssPath, rect{x,y,w,h}, textPreview, outerHtml(≤2KB), styles{~30 项 computed}, ancestors[{tag,id,classes}] }`。
- `CONSOLE_INIT_JS`：初始化脚本（见上），每条 `{ level, text, time, src }`，`__xrConsoleCursor` 供增量。
- `CONSOLE_READ_JS` / `CONSOLE_CLEAR_JS`。
- `ZOOM_JS_TEMPLATE`：`document.documentElement.style.zoom`（wry 跨平台 set_zoom 不可靠，用 CSS zoom）。

### 2. `src-tauri/src/browser.rs`
- `create_webview`：builder 加 `.initialization_script(CONSOLE_INIT_JS)`。
- `BrowserState` 加 `inspect: Mutex<bool>`，attach/重建后按标志重装覆盖层。
- 新增 tauri 命令（都是「取 webview，无则 Err」+ `eval_json` 薄封装）：`browser_inspect_set`、`browser_inspect_poll`、`browser_console_get`、`browser_console_clear`、`browser_set_zoom`。
- `run_tool` 第一期不动（第二期加分支）。

### 3. `src-tauri/src/lib.rs`
- `invoke_handler` 注册上面 5 个新命令。

### 4. `components/agent-thread/agent-panel/browser-view.tsx`
- 顶栏加**检查光标开关**按钮（`CheckIcon`/`ScanIcon`）。
- 布局重排为：`[顶栏] [flex-1 行: 画布(flex-1) + 检查器侧栏(可折叠,~300px)] [控制台底栏] [视口条]`。
- 视口条：预设按钮旁加**可编辑 W×H 数值输入** + **缩放 % 下拉**（调 `browser_viewport_set`/`browser_set_zoom`）。
- 轮询逻辑 + 选中态提升到本组件，喂给侧栏与控制台。
- 「添加到对话」按钮：把选中元素（cssPath + HTML 片段 + 关键样式）和/或勾选的 console 条目拼成 markdown 代码块，`window.dispatchEvent(new CustomEvent("composer:append",{detail:{text}}))`。

### 5. 新组件 `browser-inspector.tsx`（右侧栏）
- **组件** tab：由 `ancestors` 渲染缩进 DOM 树，高亮选中项。
- **设计** tab：位置(X/Y/Z)、旋转、布局(Flow/W/H/Padding/Margin/Border box)、外观(不透明度/圆角)、文本(字体/字号/字重/颜色/对齐)——全部 computed style **只读**展示（编辑后置）。
- **CSS** tab：尝试 `document.styleSheets` 匹配该节点规则；跨域表抛 `SecurityError` 时降级为只显 computed styles。

### 6. 新组件 `browser-console.tsx`（底栏）
- 条目列表 + 级别图标/颜色、错误计数徽标、筛选（按级别）、清除、「添加到对话 · N」。

### 7. `components/agent-thread/cm-composer-input.tsx`
- 监听 `composer:append` 事件，`setText(当前值 + "\n" + 块)`（复用现有跨组件事件模式，如 `agent-panel:open`）。

## 第二期：agent 工具（复用上面宿主原语）

- `browser-tools.ts`：加 `browser_console`（读日志，level 过滤）、`browser_inspect`（按 ref 返 computed style+DOM 路径+HTML 片段）、`browser_evaluate`（执行任意 JS，输出截断+5s 超时，沿用 browser 开关门控）、`browser_screenshot`（按 `BrowserState.frame` 区域截图）4 个 schema + execute。
- `tool_exec.rs`：`browser_*` match 臂补上这 4 个名字。
- `browser.rs run_tool`：加 4 个分支（`browser_screenshot` 走 `screencapture -R x,y,w,h` 区域裁剪，复用 `handle_screenshot` 的 sips 压缩链）。
- `hostdb.ts`：`toolRpcTimeoutMs` 已覆盖 `browser_*`（60s+余量），无需改。
- 测试：`browser-tools.test.ts` 补 4 个工具的 schema/门控用例。

## 诚实的限制（需你知悉）

1. **截图里那条 `net::ERR_ABORTED …/chat/….mp4` 大概率不会出现在控制台**——它是浏览器网络层错误，页面 JS 抓不到（只有 Chrome CDP 能）。第一期控制台只覆盖 `console.error` + fetch/XHR 包装的失败。你已选「接受降级」，这里再明确一次。
2. 跨域 iframe 不覆盖（与现有 snapshot「main frame only」一致）。
3. CSS zoom 会让 inspect 报告的 rect 处于缩放后的 CSS 像素坐标系。
4. 初始化脚本在 webview 创建时注入；本功能上线前已打开的页面需刷新一次才有 console 捕获。

## 测试与验证

- 侧车：`bun run --filter pi-agent-sidecar test`（第二期工具用例）。
- Rust：`cargo test`（沿用现有 `parse_web_url` 等纯函数测试风格；注入脚本以字符串组装正确性为主）。
- 手动：`tauri:dev` → 开浏览器 tab → 导航百度 → 点检查光标 → 选元素看侧栏三 tab → 看控制台错误 → 点「添加到对话」看 composer 是否收到块 → 改视口数值/缩放看 webview 是否跟随。

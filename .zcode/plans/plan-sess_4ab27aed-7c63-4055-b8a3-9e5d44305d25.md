# 每个会话独立的 Agent 面板标签组

## 目标

右侧 Agent 面板保持单面板布局，但标签集合按会话隔离：切换会话时整组切换到该会话自己的标签组（含激活的标签），全部标签类型（含终端/浏览器）按会话独立；不做旧数据迁移（清空重来，删除旧 localStorage 键）。

## 现状关键事实（已核实）

- `apps/desktop/lib/panels/panel-tabs.ts`：模块级单例 store，`{tabs, activeId}` 一套，localStorage 键 `agent-panel-tabs`；所有 mutator（openPanelTab/focusPanelTab/close…）全局生效。
- `apps/desktop/components/agent-thread/agent-panel/index.tsx`（PanelShell）：渲染当前 tabs；两个浏览器 webview 生命周期 effect 以「当前 tabs 里 browser 数量归零」判定销毁（`browser_detach destroy:true`）。
- `apps/desktop/lib/shell.ts` `syncSessionsToTabs()`（:138-153）：以当前全局标签集合为唯一事实源回收未绑定的 PTY 会话。
- 浏览器 webview 是原生层单例，`browser_attach`/`detach(destroy:false)` 幂等，重挂载不丢页面状态 → 切会话往返天然安全。
- 线程删除统一漏斗：`lib/pi/pi-runtime/runtime/usePiRuntime.ts:646-648` adapter `delete` → `client.deleteThread`（thread-list.aui / archive-settings / automations-view 三处 UI 入口都走这里）。
- 当前线程 id 标准取法：`useAuiState((s) => s.threads.mainThreadId)`；`panel-activity` 数据层本就跟随当前线程，无需改。

## 改动方案

### 1. `lib/panels/panel-tabs.ts` 改造为按线程分桶（核心）
- 存储形状 v2：`{ byThread: Record<threadId, {tabs, activeId}>, order: threadId[] }`，新 localStorage 键 `agent-panel-tabs-v2`；hydrate 时 removeItem 旧键 `agent-panel-tabs`（用户已选清空重来）。
- 模块级 `currentThreadId` 指针 + 新 API：
  - `setCurrentPanelThread(threadId | null)`：切指针、touch LRU、notify 订阅者（`usePanelTabs()` 快照随之切到新线程的桶）。
  - `getAllThreadTabs()` / `useAllThreadTabs()`：跨线程全量视图，供 shell 桥与浏览器计数用。
  - `purgeThreadPanelTabs(threadId)`：会话删除时清桶并 commit（触发 shell 桥回收该会话的 PTY、浏览器计数重估）。
- 所有既有 mutator **签名不变**，落点改为「当前线程的桶」；指针为 null 时 no-op 防御。
- LRU 上限（30 个会话）防 localStorage 无界膨胀；空桶不落盘；「reload 不恢复 browser 标签」规则扩展到所有桶。
- 实现注意：缺失桶返回稳定空态常量（避免 useSyncExternalStore 快照不稳定导致无限重渲）。

### 2. `components/agent-thread/base.tsx`：登记当前线程
- Base 内 `useAuiState((s) => s.threads.mainThreadId)` + effect 调 `setCurrentPanelThread`。选 Base（而非 AgentPanel）是因为它常驻挂载——面板从未展开时，lib 层的 focusPanelTab（agent 工具、subagent 委派行等）也能落对桶。

### 3. `components/agent-thread/agent-panel/index.tsx`：浏览器销毁判定改全局口径
- PanelShell 两处「browser 数量归零 → destroy webview」effect 改用全部线程桶的 browser 标签总数，否则切走会话会误销毁其他会话正开着的浏览器 webview。渲染层（TabBar/空态/TabContentView）不动。

### 4. `lib/shell.ts`：PTY 回收改全局并集
- `syncSessionsToTabs` 改为遍历 `getAllThreadTabs()` 收集所有会话的 shell 绑定后再回收，否则切会话会杀光其他会话的终端。

### 5. `lib/pi/pi-runtime/runtime/usePiRuntime.ts`：会话删除钩子
- adapter `delete` 成功后调 `purgeThreadPanelTabs(remoteId)`（panel-tabs 无反向依赖，无循环引用）。

### 6. 测试
- 重写 `lib/panels/panel-tabs.test.ts`：线程隔离（A 开的标签 B 不可见）、指针切换、purge、LRU 驱逐、reload 过滤、持久化形状。
- 用 `bun test` 跑 panels 相关测试回归。

## 明确不改
- tab-registry / tab-bar / 各标签视图 / tool-panel.ts / subagent-runs.ts / pi-client-base.ts 等调用方（API 签名不变，`getPanelTabs` 语义自动变为「当前会话内查找」，subagent 复用语义正确）。
- 布局（单右列面板）、panel-activity 数据层、compact 浮层逻辑（与宽屏共用同一 store，天然一致）。

## 风险
- 键为 assistant-ui 线程 id：draft→首条消息后保持稳定；应用重启后若 resume 映射换了 local id，最坏情况是该会话面板从空态开始（标签廉价，可接受）。
- `focusPanelTab` 的「同类型复用」语义变为会话内复用——跨会话各开各的，正是本需求。

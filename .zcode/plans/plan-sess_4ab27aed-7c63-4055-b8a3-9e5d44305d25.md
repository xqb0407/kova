# 修复：后台会话的 agent 工具把标签开进你正在看的会话

## 根因（已核实）

分桶改造后，`panel-tabs.ts` 的所有 mutator（`focusPanelTab`/`focusPluginPanel`/`closePanelTab`/`updatePanelTab`…）都经 `mutateCurrent` 落到**显示指针**指向的桶。而 agent 驱动的两条写入路径没有按属主定靶：

1. `pi-client-base.ts` 的 `data-panelOpen`（browser/file）和 `data-pluginOpen` 帧处理：帧里带着属主 `sid = parsed.sessionId`（分桶键恰好就是 sessionId，rekey 后一致），却调用指针版 API，并**无条件** `dispatchEvent("agent-panel:open")`。→ 会话 B 的浏览器工具在你看会话 A 时把标签开进 A 的桶、还把面板弹到 A 面前（全屏劫持即用户所见）。
2. `shell.ts` 的后台终端回写：进程退出 `closePanelTab(session.tabId)`、OSC 标题 `updatePanelTab(...)`、`claimTabTitle` 也都走指针桶 → 后台会话进程退出时关掉的是你当前会话里恰好同 id 的标签（找不到则桶留死标签）。

`openSubagentTab`/tool 行点击是用户点击触发，落当前桶正确，不动。

## 改动

### 1. `lib/panels/panel-tabs.ts`：新增按属主定靶的写入通道
- 抽出 `mutateThread(threadId, fn)` 作为核心变更通道（目标桶缺失即新建——后台会话的首个标签不必等它被查看；引用相等不提交、LRU touch、commit 语义与现在一致）；`mutateCurrent` 改为其 `currentThreadId` 委托（保留指针为 null 时 no-op 防御）。
- 把 open/focus/close/update 的实现体下沉为内部 `*In(threadId, ...)` 助手，现有指针版导出签名不变、改为调用助手。
- 新导出：`getCurrentPanelThreadId()`、`getPanelTabsFor(threadId)`、`openPanelTabFor`、`focusPanelTabFor`、`focusPluginPanelFor`、`closePanelTabFor`、`updatePanelTabFor`。
- 纯 UI 操作（closeAll/Other/Left/Right、activate、setActive）保持指针版——它们只可能发生在被显示的会话上。

### 2. `lib/pi/pi-runtime/pi-client-base.ts`：工具帧按属主落桶 + 事件门控
- 两处 block 统一 `const owner = sid ?? getCurrentPanelThreadId();`（owner 为 null 直接 return，防御无 sid 的异常帧）。
- `focusPanelTab` → `focusPanelTabFor(owner, ...)`，`focusPluginPanel` → `focusPluginPanelFor(owner, ...)`。
- `agent-panel:open` 与 `plugin-panel:refresh` 仅在 `owner === getCurrentPanelThreadId()` 时派发：后台会话静默写桶，不抢面板；切回属主会话时标签自然出现（浏览器单例 webview 只随显示桶的 active browser tab 挂载，不再被后台导航，劫持消失；plugin 的 path/cwd 已写进 tab extra，重挂载自取）。

### 3. `lib/shell.ts`：终端会话记录属主
- `ShellSession` 增加 `ownerThread: string | null`，`newTerminalTab`/`restartShellTab` 里取 `getCurrentPanelThreadId()` 记入。
- 进程退出关闭、OSC 标题回写、`claimTabTitle` 的查找，改用 `closePanelTabFor`/`updatePanelTabFor`/`getPanelTabsFor(session.ownerThread ?? getCurrentPanelThreadId())`。
- 顺带修复：后台进程退出不再在你看的会话里遗留/误关标签。

### 4. 测试
- `panel-tabs.test.ts` 追加：`focusPanelTabFor` 写后台桶不碰显示桶（显示快照引用不变）、桶不存在即新建且进并集视图、`closePanelTabFor`/`updatePanelTabFor` 定向生效、指针版在 null 指针下 no-op；原 11 条回归全过。
- 验证：`~/.bun/bin/bun test apps/desktop/lib/` + `apps/desktop/node_modules/.bin/tsc --noEmit`。

## 不改
- Base 指针登记、rekey/purge、浏览器销毁全局计数、PTY 并集回收——这些已是正确设计，本修复只是让"写入方"也开始按属主定靶。

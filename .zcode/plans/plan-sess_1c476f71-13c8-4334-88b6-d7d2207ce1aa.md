## 目标

在主输入框底栏、模型选择器旁边加一个「优化提示词」按钮：点击后把当前草稿交给**会话当前模型**做一次独立 one-shot 改写，结果回填输入框；草稿里的 skill 芯片、子 agent 芯片**一个字节都不动**；优化进行中整个输入框卡片被一层动画遮罩盖住（全锁）。

## 一、核心技术前提（已在代码里确认）

- 芯片不是 DOM 对象，而是 CodeMirror 文档里的**序列化文本** `:type[标签]{name=id}`（`cm-directive.ts:29` 的 `DIRECTIVE_RE`），渲染只是 `Decoration.replace`。所以「不动芯片」= 文本层保护，可以纯函数实现、可单测。
- sidecar 已有同源正则与 one-shot 范式：`sessions/session-title-summarize.ts` 用 `getModels().streamSimple(model, context)` 发**不进会话上下文**的独立请求。优化走同一条路。
- 回填用 `aui.composer.setText(...)`（`prompt-queue-bar.tsx:56` 已这么用）；`cm-composer-input.tsx` 的 `reconcile()` 会把外部 setText 最小 diff 回写文档，芯片文本天然还原。
- ⌘Z 免费可用：CM 装了 `history()`，回填走一次 doc 变更，撤销即回到原稿。
- 前端一次性 RPC 走 `piRequest()`（`pi-bridge.ts:990`）；Rust 侧 `pi_request` 无超时、按 id 配对（`pi_agent.rs:340`），**慢响应只要前端传大 timeoutMs 即可**。
- **硬约束**：非 prompt 命令进 `enqueueMgmt` 严格串行队列（`mgmt-queue.ts`）。几秒的 LLM 调用绝不能占队列——handler 只做校验+派活就返回，结果晚点用同一个 `reqId` 发回。

## 二、芯片保护设计（本方案的关键）

在 **sidecar** 做（`DIRECTIVE_RE` 与桌面端同源），协议只传原始文本，桌面端不掺和转义：

1. `maskDirectives(text)`：按 `DIRECTIVE_RE` 扫出芯片，逐个替换成占位符 `[[c1]] [[c2]] …`，同时存表 `Map<n, 原始序列化文本>`。
2. one-shot 请求：masked 文本 + 系统提示词，规则含「占位符必须原样保留、每个恰好出现一次、可挪到语义合适的位置」「只输出优化后的正文，无解释/无代码围栏/保持原语言」「不得虚构用户没提的需求，不要回答这个任务本身」。
3. `restoreDirectives(masked, table)`（**表驱动还原**）：
   - 还原用容错正则（先精确 `[[cN]]`，再宽松匹配 `[cN] / {{cN}} / ⟦cN⟧` 等被模型改写的形式），**但内容一律取自自己的表**，绝不采用模型输出的芯片文本 → 芯片不可能被改坏，只可能被挪位/丢失；
   - 校验修复：缺失的芯片按原相对顺序补到文末；重复的只留首个；表外幻影占位符一律删除；
   - 兜底清洗：剥掉包裹的代码围栏、去「优化后：」这类前缀、首尾 trim；结果为空视为失败。

失败口径：模型报错/空输出/超长 → 返回标准 `error` 帧，前端 toast 说明，**草稿保持原样**。

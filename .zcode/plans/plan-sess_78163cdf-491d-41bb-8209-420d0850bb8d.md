# API Key 泄露面全面加固方案

## 背景（已核实的事实）
- Key 明文存于 `state.db` 的 `credentials.api_key` 列（`apps/desktop/src-tauri/src/data.rs:29-33, 518-527`），无任何加密，无 keyring/stronghold 依赖。
- `list_custom_providers` 把明文 apiKey 返回给渲染进程（`apps/sidecar/pi-agent/src/protocol.ts:1909-1918`），供编辑弹窗回填。
- 远程网关绑 `0.0.0.0:8787`（`apps/desktop/src-tauri/src/remote.rs:305`），鉴权后**无类型过滤**原样透传协议（remote.rs:712-756）；远程浏览器加载的是完整桌面 UI（`components/runtime/app-runtime-provider.tsx:233`），可读明文 key、写凭据。
- sidecar 生产路径全部经 stdoutRpc 走 Rust 读写数据库（`hostdb.ts:6-12`），bun:sqlite 直连仅测试模式 → **加密可集中在 Rust 层一处**。
- CSP 为 null（`tauri.conf.json:39`）。

## A. 加密落盘（Rust，`apps/desktop/src-tauri/`）
1. 新增 `src/secret.rs`：
   - 主密钥：随机 32B，存 OS keychain（`keyring` crate v3，service `com.xulux.assistant`，account `master.key`）；keychain 不可用时**降级为明文存储并 log::warn**（不阻断 Linux 无 libsecret 场景）。
   - `encrypt_str/decrypt_str`：AES-256-GCM，随机 nonce，格式 `enc:v1:<base64(nonce||ct)>`；无此前缀的旧值按明文读取（兼容）。
2. `Cargo.toml` 加 `keyring = "3"`、`aes-gcm = "0.10"`、`rand`、`base64`。
3. `data.rs`：`credential_set` 入库前加密；`credential_get`/`credential_list` 路径解密；解密失败返回 null 并日志（提示用户重输 key）。
4. `store.rs` 打开 DB 后跑一次性迁移：`credentials` 中无 `enc:v1:` 前缀的行逐条加密重写。
5. `remote.rs:414` 的 `remote.token` kv 值同样加密（在 store::kv_set/kv_get 对指定敏感 key 走 secret.rs；或调用点显式加密）。
6. `hostdb.ts` local 测试模式保持明文（仅测试路径），加注释说明。

## B. 移除前端明文回传
1. `protocol.ts` `list_custom_providers`：`apiKey` 字段改为掩码（`sk-****` + 后4位，从内存中取值拼接，不落库），保留 `hasApiKey`。
2. `protocol.ts` `test_provider`：新增可选 `providerId`；apiKey 为空时服务端用 `credentialGet(providerId)` 兜底（否则编辑弹窗"测试连接"在用户不重输 key 时会失败）。`fetch_models` 同理仅在新增弹窗用，不动。
3. `components/settings/components/model-settings.tsx`：编辑弹窗不再回填真实 key（改线 680、788 处），输入框占位「已保存 ····{后4位}，留空保持不变」；提交时空串=不更新（`add_custom_provider` 已支持 protocol.ts:1873-1876）。**关键防护：掩码串绝不能被当新 key 提交回库**。
4. `lib/pi-bridge.ts:94-95` 类型与注释更新（掩码，非明文）。

## C. 远程网关收敛（`remote.rs`）
1. `forward_to_agent` 加**敏感类型黑名单**，命中即回 `{"type":"error","errorText":"该操作仅限桌面端"}`：`set_credential`、`delete_credential`、`list_credentials`、`add_custom_provider`、`delete_custom_provider`、`toggle_custom_provider`、`test_provider`、`fetch_models`、MCP 管理类（实施时枚举 protocol.ts 全部 case，管理类一律拒绝，会话/聊天类 `prompt/abort/list_running/list_sessions/get_history/new_session/rename_session/fork_session/archive_session/delete_session` 等放行）。
2. 绑定模式可配置：`pi_remote_start` 增加 `lan: Option<bool>`（默认 true 保持现有跨设备能力；false 绑 `127.0.0.1`），存 kv `remote.bind`；`remote-settings.tsx` 加「仅本机/局域网」开关。
3. 新增 `pi_remote_revoke` command：删除 kv `remote.token` → 所有已配对设备下次 auth 失效，需重新扫码配对；UI 加「撤销所有设备」按钮。
4. `docs/remote-access.md` 同步更新安全说明。

## D. 杂项
1. CSP：`tauri.conf.json` 设 `default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline'; img-src 'self' data: blob: https: http:; font-src 'self' data:; connect-src 'self' ipc: http://ipc.localhost ws: wss:; worker-src 'self' blob:; frame-src 'self' data: blob:; object-src 'none'; base-uri 'self'`。生产构建后验证桌面/远程页无 CSP 报错，若 Next 导出含内联脚本则按报错收紧或调整。
2. `pi_agent.rs:283` sidecar stderr 日志先过正则脱敏（`sk-[A-Za-z0-9_-]{8,}`、`Bearer\s+\S+` → `***`）。

## 测试与验证
- Rust 单测：secret 加解密往返、旧明文迁移、解密失败降级；`cargo test`。
- 更新/新增 `protocol.test.ts`（若存在）与 `hostdb.test.ts` 相关断言：掩码返回、空 key 保留、test_provider providerId 兜底。
- 手动链路：`pnpm dev` 存新 key → 检查 `state.db` 该行为 `enc:v1:` 前缀；旧 key 启动后自动迁移；编辑弹窗不回填、留空保存后原 key 仍可用；手机端配对后 WS 里手发 `list_credentials`/`set_credential` 被拒；`pi_remote_revoke` 后旧 token 失效。
- 最后 `pnpm build` + tauri 生产构建冒烟（CSP 生效、应用可启动）。

## 取舍说明
- 网关采用黑名单而非白名单：远程页复用整套桌面 UI，白名单枚举不全易误伤聊天功能；黑名单挡住凭据/管理类，且 B 层掩码已保证即使漏网也读不到明文 key。
- keychain 不可用时降级明文 + 警告：优先保证可用性（Linux 无密钥环场景），不静默损坏数据。
- 保留 `0.0.0.0` 默认绑定：远程访问的既有用法就是跨设备，默认改绑 127.0.0.1 会破坏功能，故改为可选项。

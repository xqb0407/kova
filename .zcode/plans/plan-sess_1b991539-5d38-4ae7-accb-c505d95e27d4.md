# 回复风格支持用户自定义

## 目标
在 6 个内置风格档位之外，允许用户**新增/编辑/删除**自定义回复风格（名称 + Markdown 风格描述），选中后与内置档位同样注入系统提示词并热生效；整包沿用现有「草稿 + 600ms 防抖自动保存」链路，**不新增协议消息**。已确认：内置预设不可改写；编辑器复用 CodeMirror Markdown 弹窗。

## 数据模型（事实源：sidecar）
`apps/sidecar/pi-agent/src/personalization.ts`：

- 类型改造：
  ```ts
  export type PersonalizationBuiltinStyle = "default" | "professional" | ... | "guiding";
  export type PersonalizationStyle = PersonalizationBuiltinStyle | `custom:${string}`;
  export type PersonalizationCustomStyle = { id: string; name: string; prompt: string };
  ```
- `Personalization` 增加 `styles: PersonalizationCustomStyle[]`；`DEFAULT_PERSONALIZATION.styles = []`。
- `STYLE_PROMPTS` 键型改为 `Record<PersonalizationBuiltinStyle, string>`（内容不动）。
- `structuredSettings()` 落 kv 时带上 `styles`；旧版 kv 无此字段 → normalize 回落 `[]`（向后兼容，仿照现有 legacy 迁移的宽松策略）。
- `normalizePersonalization` 扩展：
  - `styles` 逐条净化：`id` 字符串（≤64）、`name` trim（≤24 字）、`prompt`（≤4000 注入预算）；按 id 去重、条数上限 20。
  - `style`：命中内置名单，或 `custom:<id>` 且 id 存在于净化后的 styles 列表才保留，否则回落 `"default"`（删除当前选中的自定义风格时天然回落）。
- `personalizationPromptBlock()`：style 为 custom 时改注入 `Reply style - ${name}: ${prompt}`（prompt 原样注入，用户用中文写也没问题）；其余不变。全默认时仍输出空串（缓存友好承诺不破）。
- 顶部注释与 `protocol.ts` 头部协议注释（第 49–50 行）补充 styles 字段说明。`protocol.ts` 逻辑零改动（`set_personalization` 已热替换活动会话提示词，整包携带 styles 即可）。

## 前端镜像
`apps/desktop/lib/pi-bridge.ts`：镜像上述类型（`PiPersonalizationStyle` 变为 id 联合、新增 `PiPersonalizationCustomStyle`、`PiPersonalization` 加 `styles`）。

`apps/desktop/lib/personalization.ts`：
- `DEFAULT_PERSONALIZATION` 加 `styles: []`；`PERSONALIZATION_STYLE_OPTIONS` 改注释为「内置档位」。
- 小工具：`customStyleIdPrefix = "custom:"`、`makeCustomStyleId()`（`crypto.randomUUID().slice(0,8)`）。

## 设置页 UI
`apps/desktop/components/settings/components/personalization-settings.tsx`：
- 风格网格 = 内置卡片 + 自定义卡片（label=名称、desc=prompt 首行截断）+ 末尾「+ 新建风格」虚线卡片；选中态逻辑不变（`draft.style === 值`，自定义为 `custom:<id>`）。
- 自定义卡片 hover 显示右上小编辑/删除图标：
  - 编辑 → 打开弹窗；保存走 `update({ styles: [...] })` 进既有防抖自动保存。
  - 删除 → `update` 移除该条；若正选中该风格，同时 `style: "default"`。
- 弹窗：`MarkdownEditDialog` 增加可选 `extraContent?: ReactNode`（渲染在标题与 Tabs 之间），新建风格场景放入受控「风格名称」`Input`；组件本身仍懒加载分块不变。名称为空时回落「未命名风格」。
- 文案硬编码中文（项目无 i18n，跟现状一致）。
